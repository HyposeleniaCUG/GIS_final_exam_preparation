# GIS_final_exam_preparation

《**GIS原理**》（地理信息系统原理）期末复习用的 **豆包 AI 刷题助教** 技能包。

＃＃呃，其实你可以直接打开02 GIS考点知识库.md背就行了
（手机端豆包操作太麻烦）

导入豆包后，它会**出题考你**（按真题的题型和分值）、**批改并给分**（按采分点逐条对照）、**讲重点**（是什么 → 为什么 → 怎么答 → 易错在哪 → 怎么记）。

> 适用：中国地质大学（武汉）《GIS原理》课程期末复习。

---

## 🚀3 分钟装好

### 方式一：指令 + 知识库（推荐，效果最好）

1. 打开 [豆包](https://www.doubao.com)，找到「**创建智能体 / 创建我的 AI**」。
2. **名称**：`GIS原理期末助教`　**简介**：`会出题、会批改、会讲重点的 GIS 原理复习助教`
3. 把 `01 豆包指令（粘贴到智能体）.md` 里 **「=== 指令开始 ===」到「=== 指令结束 ===」之间** 的内容，整段粘贴进「**指令 / 人设与回复逻辑**」框。
4. 把 `02 GIS考点知识库.md`（或同内容的 `.txt`）上传到「**知识库 / 文件**」。
5. 保存 → 开始对话，发一句：**`开始吧，先给我菜单`**。

### 方式二：智能体没有知识库入口

按上面第 3 步建好智能体后，进对话把 `02 GIS考点知识库.md` 全文分 2–3 条发过去，先说：

> 我把课程考点资料发给你，请先读一遍并记住，读完只回复"已读完，可以开始出题"，不要总结。

读完后再发：**`现在按你的指令开始工作，先给我菜单`**。

### 方式三：指令框有字数限制

用 `04 单文件整合版.md / .docx`：里面的 **「第一部分｜精简版指令」**（约 1300 字）粘进指令框，**「第二部分｜考点知识库」** 作为第一条消息发给它。

## ⚠️ 几点说明

- **本课评分规则**（老师原话）：分析题中基础概念解释错误，该题后续作答**不予评分**。所以名词解释、定义必须背到关键词——这也是助教批改时最盯的点。
- 课件缺**比例尺**一节，`比例尺精度 = 0.1mm × 分母` 按通用测绘学补充，知识库中已标注「待核」。
- 真题照片中有 3 处原件印刷错误（"网格 GIS"应为"网络 GIS"等），按原文保留并注明。
- **AI 出题只是练手，一切以课件和老师复习提纲为准。** 遇到它答错，请以课件 PDF 核对。

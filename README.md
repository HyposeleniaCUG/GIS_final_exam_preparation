# GIS_final_exam_preparation

《**GIS原理**》（地理信息系统原理）期末复习用的 **豆包 AI 刷题助教** + **老师重点逐条答案**。

## **呃，其实你可以直接打开 05 老师重点逐条答案.md 背就行了**

（手机端豆包操作太麻烦；想翻全量考点就看 `02 GIS考点知识库.md`）

导入豆包后，它会**出题考你**（按真题的题型和分值）、**批改并给分**（按采分点逐条对照）、**讲重点**（是什么 → 为什么 → 怎么答 → 易错在哪 → 怎么记）。

> 适用：中国地质大学（武汉）《GIS原理》期末（老师已划重点：第一、二、三、四、五、六、七、九章八个部分）。

## 3 分钟装好

### 方式：指令 + 仓库链接（最简单）

打开 [豆包](https://www.doubao.com)，建立新的对话，选择**工作模式**，把这个仓库链接甩给豆包，然后对她说：**“豆姐，你给我拉取这个仓库，我要给你装这个 skill 技能包”**，然后按提示选就行了。

### 备选一：指令 + 知识库（推荐，效果最好）

1. 打开 [豆包](https://www.doubao.com)，找到「**创建智能体 / 创建我的 AI**」。
2. **名称**：`GIS原理期末助教`　**简介**：`会出题、会批改、会讲重点的 GIS 原理复习助教`
3. 把 `01 豆包指令（粘贴到智能体）.md` 里 **「=== 指令开始 ===」到「=== 指令结束 ===」之间** 的内容，整段粘贴进「**指令 / 人设与回复逻辑**」框。
4. 把 `02 GIS考点知识库.md`（或同内容的 `.txt`）上传到「**知识库 / 文件**」。
5. 保存 → 开始对话，发一句：**`开始吧，先给我菜单`**。

### 备选二：智能体没有知识库入口

按上面第 3 步建好智能体后，进对话把 `02 GIS考点知识库.md` 全文分 2–3 条发过去，先说：

> 我把课程考点资料发给你，请先读一遍并记住，读完只回复"已读完，可以开始出题"，不要总结。

读完后再发：**`现在按你的指令开始工作，先给我菜单`**。

### 备选三：指令框有字数限制

用 `04 单文件整合版.md / .docx`：里面的 **「第一部分｜精简版指令」**（约 1300 字）粘进指令框，**「第二部分｜考点知识库」** 作为第一条消息发给它。

## 📌 今年考试情报（老师原话整理）

- **范围**：主要是一、二、三、四、五、六、七、九章八个部分；第八章地图符号考得少，第 10~13 章不是重点。
- **题型**：**40 道选择题** ＋ 名词解释 ＋ 简答（一题对应一个知识点）＋ **2 道分析题**（生活应用、一对多）。
- **第六章重点是 6.4 空间索引 和 6.6**（老师说大题主要出这两节）；**第七章空间分析必出 1~2 道大题**，且会把编码、索引、空间分析串起来考。
- **评分规则**：**分析题中基础概念解释错误，该题后续作答不予评分**——所以定义必须背到关键词。
- **复习要求**：不考复杂公式；只看 PPT 最高不过 80 分，要结合绿书《地理信息系统原理与方法》；不用一字不漏，理解即可得分；**建议做 AI 题 10 套以上**。

## ⚠️ 几点说明

- 第 1 章课件作者是禹文豪教授，教务系统截图里任课教师是周琪，同一门课，口径一致。
- 课件缺**比例尺**一节，`比例尺精度 = 0.1mm × 分母` 按通用测绘学补充，知识库中标了「待核」。
- 真题照片里有 3 处原件印刷错误（如「网格 GIS」应为「网络 GIS」），按原文保留并注明。
- 6.6 时空数据模型在课件中只有目录没有正文，按教材口径补齐（真题考过「序列快照模型」「基态修正法」）。
